1. Global Architecture & Conventions
1.1 Tech Stack
Next.js App Router
Routing — /auth/*, /dashboard, /users/*, /assets/*, /condition-reports/*, /reports
Tailwind CSS
Styling — utility-first, no global CSS sheets
React Hook Form + Zod
Form state & validation — zodResolver bridges schemas to forms
TanStack Query v5
Server state — useQuery (reads), useMutation (writes), cache invalidation
URL Search Params
UI filter & pagination state — URL is single source of truth
React Context API
Global identity — AuthContext stores token + user profile (id, name, role)
Lucide React
Icon library
1.2 Standard API Envelope
Every API response is wrapped in a consistent envelope. Clients must check success first, then read data (success) or
error (failure). Paginated responses include data.items[] and data.pagination { page (0-indexed), size, totalElements,
totalPages }.
1.3 Zero-Local-State Error Pattern
Rule: Never use useState to track server errors in forms. All mutation errors are mapped through React Hook Form's
setError:
 Field errors (409/422) → setError("fieldName", { message })
 Auth errors (401) → setError("root", { message }) — never field-specific (prevents enumeration)
 Server errors (500) → setError("root.serverError", { message })
1.4 URL-as-State (Filters & Pagination)
Rule: Filter and pagination state live exclusively in URL query params via useSearchParams(). Zod schemas coerce URL
strings to typed values and translate UI 1-indexed pages to API 0-indexed pages. Updates use router.replace() —
triggering automatic TanStack Query refetch via the query key.
